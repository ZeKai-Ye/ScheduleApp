# 导入 / 导出格式：CSV（统一格式）与 iCalendar（.ics）

主界面「导入日程」既接 **CSV**，也接 **iCalendar（.ics）**；
「导出」既可以写统一格式的 CSV，也可以写 .ics（可直接导入 Google 日历 / Outlook）。

> **CSV 只有一套格式**：本文第 1 节的那 17 列。旧文件的各种列名（主题 / 名称 / 开始 / 描述 …）仍然能导入，
> 但会提示「与统一格式有差异」；**列名完全对不上时会明确报错并阻止导入**，不会默默导入 0 条或导入垃圾数据。

---

## 1. 统一格式（导出即此格式）

第一行照抄下面这行即可（列的先后顺序可以不同，识别按列名）：

```
标题,开始时间,结束时间,全天,分类,颜色,优先级,重复,重复间隔,星期,重复次数,重复截止,提前提醒,语音内容,提醒铃声,备注,状态
```

| 列 | 必填 | 说明 | 示例 |
| --- | --- | --- | --- |
| 标题 | ✅ | 日程名称 | 客户沟通 |
| 开始时间 | ✅ | 日期+时间；全天日程可只写日期 | 2026-09-15 15:00 |
| 结束时间 | | 留空 = 开始后 1 小时；全天日程写「最后一天」 | 2026-09-15 16:00 |
| 全天 | | 是 / 否 | 否 |
| 分类 | | 决定自动配色 | 工作 |
| 颜色 | | 红 / 蓝 / #2563EB；留空跟随分类 | 蓝 |
| 优先级 | | 高 / 中 / 低 | 高 |
| 重复 | | 无 / 每天 / 工作日 / 每周 / 每月 / 每年 | 每周 |
| 重复间隔 | | 每隔几个周期 | 1 |
| 星期 | | 每周重复的星期，顿号分隔 | 周一、周三 |
| 重复次数 | | 共重复几次，留空 = 不限 | 6 |
| 重复截止 | | 重复到哪一天（含当天） | 2026-12-31 |
| 提前提醒 | | 分钟，可多档逗号分隔；0 = 准点；也认「不提醒」/具体时刻 | 30,15,0 |
| 语音内容 | | 播报文案；可写 `档位:文案` 用竖线分隔逐档指定 | 30:还有半小时｜0:现在开始 |
| 提醒铃声 | | 音频文件路径；同样支持逐档写法 | D:\sounds\bell.wav |
| 备注 | | 详细说明 | 记得带材料 |
| 状态 | | 待办 / 已完成 / 已取消 | 待办 |

**怎么拿到模板**（三种都行，内容一致）：

- 导入窗口里点「**下载 CSV 模板**」；
- 命令行：`ScheduleApp.exe --csv-template 模板.csv`；
- 直接「导出」一次——导出的 CSV 就是统一格式，可以原样再导入（自测里就是这么验证的）。

**取值细节**

- 时间：`2026-09-15 15:00` / `2026/9/15 15:00` / `2026年9月15日 15:00` / `明天15:00`；
  单独一列「日期」+ 只写时间的「开始时间」也支持（别名兼容）。
- 全天日程：`结束时间` 写「最后一天」，例如 12-31 → 12-31 表示一天，12-31 → 01-02 表示三天。
- 提醒：`30,15,0`（提前 30/15 分钟 + 准点）、`提前30分钟、提前5分钟`、`不提醒`、
  或直接写时刻 `2026-09-15 14:30`（作为指定时刻提醒）。
- 编码：UTF-8（推荐，带不带 BOM 都行）/ GBK / GB18030 / UTF-16，默认自动识别。
- 分隔符：逗号 / 分号 / 制表符 / 竖线都会自动判断。

## 2. 导入时的检查（为什么以前会"静默报错"）

以前的问题：表头完全对不上时，程序按"第 1 列是标题、第 2 列是开始时间"硬套，
把「姓名/电话/地址」这类文件导成一堆垃圾数据，界面还显示"导入完成 0 条"或者干脆没有提示。
现在导入窗口会：

1. **表头诊断**：列出「识别到的字段」「没认出来的列」「标准格式里缺的列」；
2. **缺必填列**（标题 / 开始时间）→ 顶部红色提示 + 给出标准表头 + **禁用「开始导入」**，
   即使强行调用也会**整单不导**（一条数据都不改），并说明原因；
3. **没有表头且第一行也解析不出** → 同样阻止，并提示把「表头」改成"第一行是表头"或手工指定列映射；
4. 多余列：只提示"会被忽略"，不影响导入；
5. 逐行失败：给出行号与原因（最多显示 30 条）；
6. **导入完成后的报告不会被刷新清掉**（以前刷新预览会把报告擦掉，用户什么都看不到）；
7. 一条都没导入时会弹窗说明原因。

## 3. 兼容的老列名（别名）

| 标准列名 | 也认这些写法 |
| --- | --- |
| 标题 | 主题、名称、事项、日程、事件、任务、安排、摘要、title、subject、summary |
| 开始时间 | 开始、起始、开始日期、开始时刻、start、begin、from、dtstart |
| 结束时间 | 结束、截止、终止、end、finish、until、to |
| 备注 | 说明、描述、详情、内容、注释、notes、description、remark |
| 分类 | 类别、类型、标签、分组、项目、category、tag、group |
| 优先级 | 重要、重要程度、紧急、priority |
| 重复 / 间隔 / 星期 / 次数 | 循环、频率、周期、间隔、每周几、共几次、rrule、interval、count |
| 重复截止 | 截止日期、重复到、直到、until |
| 提前提醒 | 提醒、提醒时间、提前、提前量、闹钟、remind、alarm |
| 语音内容 / 提醒铃声 | 语音、播报、朗读、铃声、提示音、音频、voice、speech、sound |
| 颜色 | 色彩、事件颜色、color |
| 全天 | 整天、是否全天、allday |
| 状态 | 是否完成、完成、进度、status、done |

老文件仍可导入，只是会提示「表头与统一格式有差异」。

## 4. iCalendar（.ics）

### 支持

| 内容 | 说明 |
| --- | --- |
| VEVENT | 一个文件里可以有任意多个事件 |
| SUMMARY / DESCRIPTION / LOCATION | 标题 / 备注 / 地点（地点会并进备注） |
| DTSTART / DTEND | `VALUE=DATE`（全天）、本地时间、UTC（`Z` 结尾，自动换算成本地时间）、`TZID=…` |
| DURATION | `PT1H30M` / `P1D` 等 ISO 8601 时长 |
| RRULE | `FREQ=DAILY/WEEKLY/MONTHLY/YEARLY`、`INTERVAL`、`BYDAY`（多星期 / 工作日）、`COUNT`、`UNTIL` |
| EXDATE | 单独跳过的那几次 → 映射成"已删除的这一次" |
| RECURRENCE-ID | 单独改过的那一次 → 映射成"仅这一次"的例外（时间 / 标题等） |
| VALARM | `TRIGGER:-PT30M` 这类相对提醒（可多个 → 多档提醒）；`TRIGGER;VALUE=DATE-TIME` 绝对提醒 |
| STATUS / PRIORITY / CATEGORIES | 状态 / 优先级 / 分类（多个分类取第一个并提示） |
| 折行与转义 | 75 字节折行、换行 / 逗号 / 分号 / 反斜杠的反转义 |

### 暂不支持（会给提示，不会静默丢）

| 内容 | 处理方式 |
| --- | --- |
| `FREQ=HOURLY / SECONDLY / MINUTELY` | 提示后按**单次**导入 |
| `BYDAY=2MO`（每月第 N 个星期几） | 提示后按**每周**导入 |
| `BYMONTHDAY` 与开始日不一致 | 提示后按**单次**导入 |
| `BYSETPOS` / `BYWEEKNO` / `BYYEARDAY` | 提示后忽略这些限定 |
| VTODO / VJOURNAL / VTIMEZONE | 忽略（只处理 VEVENT） |
| `TZID` 的真实时区换算 | 按"本地墙上时间"处理（`TZID=Asia/Shanghai` 的 09:30 就是本地 09:30） |
| `TRIGGER` 为正数（开始之后提醒） | 提示后归为"准点"（本程序不支持开始后提醒） |

### 怎么用

- **导入**：「导入日程」选 `.ics` 文件即可；窗口会显示事件数、重复日程数、提醒数、例外数与全部提示。
- **导出**：主界面「导出」把类型切成 `iCalendar (*.ics)`；
  命令行用 `--export 日程.ics`（`.csv` 结尾则导出统一格式 CSV）。
- 命令行导入同样自动识别：`ScheduleApp.exe --import 日程.ics`。

## 5. 命令行速查

```powershell
ScheduleApp.exe --import 日程.csv               # 统一格式 CSV（自动识别编码）
ScheduleApp.exe --import 日历.ics               # iCalendar，自动识别
ScheduleApp.exe --import 日程.csv --mode upsert  # append（默认）/ upsert / replace
ScheduleApp.exe --export 日程.csv               # 统一格式 CSV
ScheduleApp.exe --export 日程.ics               # iCalendar
ScheduleApp.exe --csv-template 模板.csv          # 导出统一格式模板
```

导入被阻止时（格式不匹配）命令行会打印标准表头并以退出码 **5** 结束，脚本可以据此判断。
