# CSV 导入格式说明

## 最小可用文件
只要有一列能识别成「标题」、一列能识别成时间即可：

```csv
标题,开始时间
项目周会,2025-06-03 14:00
```

## 支持的列

列名**不区分中英文、可含空格与括号**，按别名打分自动匹配；也可以在导入向导里手工指定。

| 字段 | 常见列名 | 说明 |
| --- | --- | --- |
| 标题 | 标题、主题、名称、事项、日程、事件、任务、内容、title、subject、name、event、summary | **必填**，为空的行会被跳过 |
| 开始时间 | 开始、开始时间、起始时间、start、begin、from、时间 | 可只写时间（配合「日期」列） |
| 结束时间 | 结束、结束时间、截止、end、finish、until | 可留空（默认 30 分钟，全天则到次日 0 点） |
| 日期 | 日期、计划日期、date | 与「开始时间」配合，仅当开始时间只含时分时拼接 |
| 分类 | 分类、类别、类型、标签、分组、category、tag、group | 留空用导入设置里的默认分类 |
| 优先级 | 优先级、重要程度、priority、level | 高/中/低、high/normal/low、1/2/3 |
| 重复 | 重复、重复规则、循环、频率、repeat、rrule | 无/每天/工作日/每周/每月/每年 |
| 提前提醒 | 提醒、提前提醒、提前档位、提前量、闹钟、remind、alarm | 可多档，见下方写法 |
| 颜色 | 颜色、色彩、事件颜色、color | 中文色名（红 / 蓝 / 灰…）、英文色名或 #RRGGBB；留空跟随分类配色 |
| 重复间隔 | 重复间隔、间隔、每几天 | 每隔几个周期，例如 `2` 表示每 2 周 / 每 2 月 |
| 星期 | 星期、周几、重复星期 | 每周重复的星期，例如 `周一、三、五` |
| 重复次数 | 重复次数、次数、共几次 | 共重复几次（含首次） |
| 语音内容 | 语音、播报内容、朗读、voice、speech、tts | 自定义播报文本，支持占位符；留空用全局模板 |
| 提醒铃声 | 铃声、提示音、音频、sound、ringtone | 本地音频文件路径（wav/mp3/wma/m4a） |
| 备注 | 备注、说明、描述、详情、notes、description、remark | 可含换行（需用引号包裹） |
| 状态 | 状态、是否完成、进度、status、done | 待办/已完成/已取消 |
| 全天 | 全天、整天、allday、fullday | 是/否；不写时按时间是否含时分自动推断 |

## 时间写法（宽容解析）

| 写法 | 解析结果 |
| --- | --- |
| `2025-06-01 09:30` / `2025/6/1 9:30` / `2025.06.01 09:30` | 标准日期时间 |
| `2025年6月1日 下午3点` / `2025年6月1日 9点30分` | 中文写法，下午 / 晚上自动 +12 小时 |
| `20250601` / `20250601103000` | 紧凑数字格式 |
| `45000` | Excel 日期序列号（1900 日期系统） |
| `2025-06-01T09:30:00` | ISO 8601（带 Z 会转换为本地时间） |
| `明天 9:00` / `后天` / `昨天` | 相对日期 |
| `下周三 14:00` / `星期三` | 本周 / 下周某天 |
| `3天后` / `2小时后` / `30分钟后` | 相对偏移 |
| `9:30` | 只有时间，日期取「日期」列或今天 |
| `930` / `08:15:30` | 紧凑时间 / 带秒时间 |
| `03/04/2025` | 歧义格式，默认按「月/日/年」，可在解析选项里切换 dayFirst |

无法解析的行会进入导入报告的失败列表，并给出**行号与原因**，不会静默丢数据。

## 提前提醒写法

| 写法 | 含义 |
| --- | --- |
| `15` | 提前 15 分钟 |
| `10分钟` / `提前30分钟` | 提前 10 / 30 分钟 |
| `1小时` / `2天` / `1周` | 单位换算 |
| `0` | 准点提醒（开始时提醒） |
| `08:00` | 当天 08:00 提醒 |
| `2025-06-01 08:00` | 指定绝对提醒时刻 |
| `30,15,5` | 一次设置多个档位（各提醒一次） |
| `提前30分钟、提前5分钟` | 中文顿号分隔的多档写法 |
| `不提醒` / `无` / `none` / `off` | 关闭该条提醒 |
| 留空 | 使用导入设置里的默认值 |

## 导入方式

| 方式 | 说明 |
| --- | --- |
| 追加为新日程 | 全部作为新记录加入（默认） |
| 更新重复项 | 按「标题 + 开始时间」匹配，命中则覆盖字段，否则新增 |
| 覆盖全部日程 | **先清空**现有日程再导入（会二次确认） |

重复判定使用归一化后的标题（忽略大小写、空格与标点）+ 开始时间精确到秒。

## 编码
自动识别顺序：BOM → 严格 UTF-8 → GB18030 / GBK。也可在向导中强制指定。
**从 Excel 另存为「CSV UTF-8」** 最稳妥；若是「CSV（逗号分隔）」，Windows 中文版会存成 GBK，本程序同样支持。

## 分隔符与表头
- 分隔符自动探测：逗号、分号、制表符、竖线
- 表头自动判断（含已知列名且首行没有日期时间即视为表头），也可手工指定「有表头 / 无表头」
- 无表头时按位置约定：`标题, 开始, 结束, 备注, 分类`

## 周期事件写法

| 写法 | 含义 |
| --- | --- |
| `每天` / `每日` | 每天 |
| `工作日` | 周一至周五 |
| `每周` / `每周一` | 每周（不写星期则与开始时间同一星期） |
| `每周一、三、五` | 每周一 / 三 / 五 |
| `每2天` / `每隔2周` / `每3个月` | 带间隔的周期 |
| `每周共10次` | 带次数上限 |
| `每2周到2025-12-31` | 带截止日期 |

也可以把间隔 / 星期 / 次数写到独立列里（更适合 Excel 维护）。

